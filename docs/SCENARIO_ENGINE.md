# Scenario Engine

Each prospect should contain:
- role
- company
- industry
- personality
- patience
- skepticism
- current solution
- hidden pain
- common objections
- buying authority
- positive triggers
- hang-up conditions
- conversion conditions

## Behavior
The prospect should behave like a buyer, not a coach.
- do not volunteer hidden needs
- push back on generic claims
- answer good discovery questions
- interrupt sometimes in realistic/challenge mode
- may hang up after repeated poor behavior

Keep scoring rubric out of the live prospect prompt.
