# Coaching

Suggested 0–100 coaching categories:
- opening
- relevance
- discovery
- listening
- value articulation
- objection handling
- conversational control
- next-step close
- professionalism

Deterministic metrics where possible:
- talk/listen ratio
- discovery-question count
- interruption count
- filler words
- objections encountered
- objection recovery
- explicit next-step ask

Use a separate post-call evaluator from the live prospect role.

Every qualitative coaching claim should cite transcript evidence or an event/metric.
